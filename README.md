A travel poster for Nimbara, a fictional city floating above a sea of clouds at sunset — a single hero lighthouse tower, domed rooftops glowing amber, suspension bridges between floating islands, and a sea of pink-and-gold clouds below. The program writes the poster to /output/entry.png.

## Run it

```sh
python3 main.py
```
